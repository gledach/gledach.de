Plate I · the surface an agent sees

It answers in structured data, not in a page to read.

Eight tools over MCP, and every one that reports signals also reports how recently it collected them. That second part is the whole difference between a quiet market and a watcher that stopped running. 

> search_signals { company: "cursor", since: "7d", minImpact: 70 }

  {
    "signals": [
      {
        "hashId": "8f2a1c…",
        "signalType": "pricing_change",
        "impactScore": 84,
        "source": "email-google-alert",
        "title": "Cursor revises team seat pricing",
        "publishedAt": "2026-10-11T06:14:00Z"
      }
    ],
    "coverage": {
      "status": "fresh",
      "lastCollectedAt": "2026-10-16T05:30:11Z",
      "trustEmptyResult": true,
      "warnings": []
    }
  }

The coverage block is on every signal-reporting tool. status is one of fresh, slowing, stale or never, and trustEmptyResult tells an agent whether an empty answer means nothing happened or means nobody looked. Without it, a watcher that quietly died reads as a calm market.

Plate II · the collection

Eleven ways in.

Each one reads something already public, and each one is listed with what it actually reads rather than what it promises. Three of them see a move before anybody announces it.

  • 01 Feedsnpm run fetch Around sixty RSS feeds across the roster and the category: Google News, Reddit, vendor blogs, GitHub releases. The feed list derives from the roster, so retargeting rewrites it. every 30 min
  • 02 Google Alerts, by Gmailnpm run watch:gmail Alerts land in a mailbox, a parser reads them, and the result fills a local inbox database. Two zones, and the second is easy to forget: nothing reaches the dashboard until email:promote runs. The refresh token stays on your machine and never goes to the scheduler. local only
  • 03 Certificate transparencynpm run watch:certs Public certificate logs, per competitor domain. A new subdomain is issued a certificate before the thing on it is announced, which makes this the earliest view of a vertical launch anyone gets for free. every 6 h
  • 04 Sitemaps and robotsnpm run watch:sites Fetch, diff against the last snapshot, and emit on new paths, removed paths and rule changes. A page exists before it is linked. every 6 h
  • 05 Hacker Newsnpm run watch:hn Through the Algolia search API, filtered by points and recency, with points, comments, author and timestamps as structured fields rather than prose scraped out of an RSS summary. daily
  • 06 GitHubnpm run watch:github Releases, breaking-change tags and issue complaints. Sixty requests an hour unauthenticated, five thousand with a token. daily
  • 07 YouTube captionsnpm run watch:youtube Captions over HTTP, no audio download and no transcription, which is free for roughly four videos in five. A caption-less video still gets a signal saying captions were not available. Local transcription is opt in. daily
  • 08 Answer-engine visibilitynpm run watch:aeo Asks the shortlist questions a buyer asks and records which brands each engine names. Detection is a deterministic word-boundary match, not a model judging another model's output. weekly
  • 09 Model routingnpm run watch:routing A public data API, openly licensed: which models the market routes tokens to, and which applications process them. It emits only movement above a threshold, so a flat week is silent rather than noisy. daily
  • 10 Search discoverynpm run watch:tavily Mention discovery past the feeds, two queries per company, budget guarded against a free monthly tier with a cooldown between runs. daily
  • 11 Search interestnpm run watch:trends Brand queries and alternative to queries. Batched to the eight stalest per run, because the upstream rate limiter refuses thirty two in a row, so the full set rotates over four passes. weekly, 4 passes

Plate III · the argument

Infrastructure moves first. Press moves last.

The sources above are not a long list for its own sake. They are ordered by how early they speak. A certificate is issued and a sitemap grows weeks before a launch post exists, and a launch post is where most monitoring products start.

  • Infrastructureweeks
  • Hiringmonths, vague
  • Documentationhours
  • Changeloghours
  • Marketingat launch
  • Pressafter

Lead time before a move becomes public knowledge. Most tools start at the bottom of this list, which is where everyone is already looking.

Plate IV · what happens to one signal

Five stages, and it says which one it stopped at.

  1. I

    Classify

    Haiku reads the item and types it: product launch, pricing change, funding, customer win, review complaint. With no model key a keyword classifier runs instead, which is less precise and still free, and the method is recorded on the row either way.

  2. II

    Score

    Business impact from nought to a hundred, re-weighted for this job: a product launch outranks generic press coverage, which is the opposite of how a news ranker would read the same two items.

  3. III

    Store

    One row, keyed by a hash of its content. Every write is idempotent, so two operators and a scheduler can all run the same pass and the duplicates collapse. A local file by default. A hosted database only when you point it at one.

  4. IV

    Correlate

    Theme and count rules fire a convergence: a pattern several independent publishers corroborate. A launch, a hiring push and a certificate change all pointing at the same vertical is one finding, not three. Each carries a structured citation graph back to its evidence, and dedupes per week.

    npm run correlate:dry
  5. V

    Synthesise, and label it

    Battlecards from Sonnet, deep research from Opus against a hundred and eighty days of signal, five analyst modes from a written persona, and a weekly report that uses no model at all because the arithmetic is deterministic. All model output is marked as model output. A claim the evidence does not support is published as unverified rather than quietly asserted.

Plate V · the surfaces

Three consumers. The dashboard is only one of them.

For agents

Eight tools over MCP.

list_companies, search_signals, get_convergences, get_battlecard, list_briefs, get_brief, run_analyst, market_summary, plus signal:// resources for a battlecard or a brief.

Read only is the default and not merely the posture: the one tool that spends money ships with permission withheld, and opting in binds it to a rolling daily ceiling shared with the scheduler and the command line.

SCROLL

For people

Eight views on localhost.

Feed, Battle, Compare, Market, Intel, Report, Briefs and Inbox. Number keys switch mode, a command palette jumps anywhere, and Compare takes an anchor plus up to three rivals in a shareable URL.

Battlecards and analyst briefs come out as markdown you can edit. A regeneration never overwrites the part a person wrote.

SCROLL

For the scheduler

One pass, tiered.

A single entry point runs every watcher on the cadence each one deserves. The expensive passes fire weekly, the cheap ones hourly. Cadence moves the bill far more than model choice does: running a per-company model call four times as often costs four times as much and is no fresher.

SCROLL

There is also a Chrome side panel that checks any page you are reading against your own intel on device. It is experimental, it needs the dashboard running, and the test gate does not cover it. Said here rather than discovered later.

Plate VI · the same parts, a different market

Nothing here knows which market it is watching.

It ships pointed at thirteen AI coding tools. That is a configuration file, not the product.

Six layers resolve the same way, each one an environment variable, then your local file, then the shipped default: the roster, the feeds, the deal context axes, subdomain scoring, the agent policy and the answer-engine prompts. Your file is ignored by git, so you can pull upstream forever without a conflict in the only file you changed.

Feeds, repository mappings and search queries all derive from the roster rather than sitting in a list beside it. And the gate is mechanical: the test suite fails if a brand name appears anywhere outside the configuration directory, or if the dashboard's own labels drift away from the roster. Retargeting cannot leave somebody else's market behind in a watcher or a prompt, because the build refuses it. 

cp config/companies.default.mjs config/companies.local.mjs
npm run companies      # confirm what is live, and where it came from
npm test               # 15 smoke sections, 5 fixture suites, all offline

Plate VIII · the rest of the shelf

Four more, each on its own page.

Same author, different shapes. They share no stack and no interface, only the promise: free, installable, and honest about what each one cannot see.

whenrun Watches day-ahead power prices and renewable share, then starts your job in the cheapest or greenest window that still meets its deadline. Zero dependencies. Open the page phonehome A local resolver that records which domains every device on your network contacts, and says when one starts talking somewhere new. Blocks nothing, uploads nothing. Open the page recall Checks four public registers against a list of the things you actually own, and grades how sure each match is. A register it could not reach is reported as unreachable, never as clean. Plate IX · house rules

What is true of everything on this shelf.

  • Free, and the source is public

    MIT unless a dependency makes that impossible, in which case the licence is stated on the tool's own page.

  • Your machine is the runtime

    Cloud is for sharing state between machines you own. It is not where your data has to live.

  • No account to start

    Clone it and see something real. Keys, hosted databases and schedules are opt in, later, each listed with what it buys you.

  • Honest about blind spots

    Every tool ships a written audit of what it cannot see, kept beside the documentation rather than buried in it.

  • Read only until you say otherwise

    Nothing spends your money because an agent found a button. Paid actions ship disabled and behind a ceiling.

  • Generated text is labelled

    Model output is marked as model output. A tool that cannot tell you what it does not know is not finished.
