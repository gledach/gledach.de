Competitive intelligence your agents can query.

01 · the surface an agent sees

It answers in structured data, and it tells you how fresh that data is.

Eight tools over MCP. Every one that reports signals also reports when it last collected any, which is the whole difference between a quiet market and a watcher that stopped running three weeks ago.

Without that block, a dead watcher reads to an agent as nothing is happening. Which is the most expensive wrong answer this kind of tool can give.

Eleven ways in.

03 · why those eleven

Infrastructure moves weeks before the press release does.

The list is not long for its own sake. It is ordered by how early each source speaks. The three watchers marked leading are the three at the top of this chart.

Most monitoring products start at the bottom of it, which is where everybody is already looking.

04 · what happens to one item

Five stages between a feed entry and an answer.

And the tool reports which of the five it reached, rather than presenting stage two as though it were stage five.

  1. 01

    Classify

    A small fast model reads the item and types it: product launch, pricing change, funding, customer win, review complaint. With no model key a keyword classifier runs instead, free and less precise, and the method used is written onto the row either way so you can re-run the ones that matter.

  2. 02

    Score

    Business impact from 0 to 100, weighted for this job rather than for news. A product launch outranks generic press coverage, which is the opposite of how a headline ranker would order the same two items.

  3. 03

    Store

    One row, keyed on a hash of its own content, so every write is idempotent and two operators plus a scheduler can run the same pass without producing duplicates. A local file by default. A hosted database only once you point it at one.

  4. 04

    Correlate

    Theme and count rules fire a convergence, and each one carries a structured citation graph back to the evidence that produced it.

    the unit that matters

    A launch, a hiring push and a certificate change all pointing at the same vertical is one finding, not three unread rows.

  5. 05

    Synthesise, and label it

    Battlecards from a mid-sized model, deep research from the largest one across a hundred and eighty days of signal, five analyst modes driven by a written persona, and a weekly report that uses no model at all because its arithmetic is deterministic.

    Every piece of model output is marked as model output. A claim the evidence does not support is published as unverified rather than asserted quietly, and the section a person wrote by hand is never overwritten by a regeneration.

06 · who consumes it

Three consumers, and a dashboard is only one of them.

For agents

Eight tools over MCP

list_companies, search_signals, get_convergences, get_battlecard, list_briefs, get_brief, run_analyst, market_summary, plus signal:// resources for a battlecard or a brief.

Read only by default and not merely by convention: the one tool that spends money ships with permission withheld, and opting in binds it to a rolling daily ceiling shared with the scheduler and the command line.

The agent surface

For people

Eight views on localhost

Feed, Battle, Compare, Market, Intel, Report, Briefs and Inbox. Number keys switch mode, a command palette jumps anywhere, and Compare takes an anchor plus up to three rivals in a URL you can share.

Battlecards and briefs come out as markdown you can edit in anything.

Open the preview

For the scheduler

One pass, tiered by cost

A single entry point runs every watcher on the cadence it deserves: the expensive passes weekly, the cheap ones every half hour.

There is also a Chrome side panel that checks the page you are reading against your own intel, on device. It is experimental, it needs the dashboard running, and the test gate does not cover it.

07 · the same parts, a different market

Nothing in here knows which market it is watching.

It ships pointed at thirteen AI coding tools. That is a configuration file, not the product. Six layers resolve the same way: an environment variable, then your local file, then the shipped default. The roster, the feeds, the deal-context axes, subdomain scoring, the agent policy and the answer-engine prompts.

Your file is ignored by git, so you can pull upstream forever without a conflict in the one file you changed. Feeds, repository mappings and search queries all derive from the roster rather than sitting in a list beside it.

And the gate is mechanical rather than a promise: the test suite fails if a brand name appears anywhere outside the configuration directory. Retargeting cannot leave somebody else's market behind in a watcher or a prompt.

08 · seeing it first

Anything worth looking at gets its own subdomain.

You should be able to watch a tool work before you decide to install it. One address per tool, replaced in place.

Real data, not a mock

The export asks the running viewer the same questions a browser asks and inlines the answers, so a preview cannot drift from the thing it was taken from.

Dated and read only

A snapshot, not a live instance. Nothing you click reaches a database, and every number is true as of the export.

One per tool, replaced in place

A re-export overwrites the preview, so you are looking at the most recent snapshot rather than an archive of all of them.

Generated text is labelled

Battlecards, briefs and convergences are model output, not verified fact. A starting point for a person, which is how the tool itself describes them.

10 · house rules

What is true of everything on this shelf.

The tools vary. These six do not. They are the reason a tool gets published here at all.

  • Free, and the source is public

    MIT unless a dependency makes that impossible, in which case the licence is stated on the tool's own page.

  • Your machine is the runtime

    Cloud is for sharing state between machines you own. It is not where your data has to live.

  • No account to start

    Clone it and see something real. Keys, hosted databases and schedules are opt in, later, each listed with what it buys you.

  • Honest about blind spots

    Every tool ships a written audit of what it cannot see, kept beside the documentation rather than buried in it.

  • Read only until you say otherwise

    Nothing spends your money because an agent found a button. Paid actions ship disabled and behind a ceiling.

  • Generated text is labelled

    Model output is marked as model output. A tool that cannot tell you what it does not know is not finished.
