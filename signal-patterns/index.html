What this is

Not a framework. The reasoning is the reusable part.

There is no package to install and nothing to version, because the code around a decision like this usually is not the part worth keeping. The reference implementation is signal, which does all of it against a real market.

Watch what leaks

Certificates, documentation and changelogs beat press releases. Certificate logs run twenty to thirty days ahead, and changelog pages change on 73% of monitors within ninety days.

Hand it to an agent

A dashboard needs someone to open it. What you actually want is an answer to a question you have not thought to ask yet, which means structured output, stable ids, and the ability to say I am not in a position to answer.

Two open standards settle it

MCP is how an agent queries you, Agent Skills is how it learns to use you. Both of the most-used open personal-agent runtimes of 2026 speak both, and both are local first, so a local process with a queryable store fits them with no work.

Eight patterns

Each one earned its place by failing first.

The bias throughout: an AI pipeline fails silently and pleasantly. The dashboard fills up, nothing throws, and it looks healthy right until you check. Most of these are machinery for turning a quiet failure into a loud one.

# Pattern The failure it prevents
1 Store chokepoint Schema changes with unbounded blast radius
2 Canonical and mirror Regeneration silently destroying human-written content
3 Never store an uncomputed verdict A dead model writing guesses into permanent storage
4 Read-only agent surface An agent spending your money because it found a button
5 The coverage block An agent reporting nothing happened when collection is broken
6 Zone separation The lethal trifecta, when your input is attacker-reachable
7 Assertions as guardrails Every pattern above quietly eroding
8 Collect, do not write Untestable sources, and shared logic wrong in several ways at once

Where one says the incident, that is a real one, with real numbers, from a single deployment over about two months.

The shortest version

If you read nothing else.

Eight lines. Every one of them is the compressed form of something that went wrong first.

  • Watch what leaks, not what is announced. Certificates, docs and changelogs beat press releases.

  • Cadence is the cost dial, not model choice. A per-subject job on the wrong tier cost one deployment around two hundred dollars a month for no added freshness.

  • Batch and cache before you optimise anything else. A flat half, then reads at a tenth.

  • A failed model writes nothing. A halted run announces itself. A run that writes guesses does not.

  • Return I do not know as data. Empty and broken look identical to an agent.

  • Agents read by default. Every paid or state-changing action is opt in, behind a shared ceiling, and permission must not scale with capability.

  • A skill is a supply chain. 341 malicious skills were found among roughly 13,000 in one 2026 marketplace audit.

  • Every rule above needs an assertion, or it is a comment.

If one of these is wrong, or you have a counter-example where it cost more than it saved, open an issue. A pattern that has never been argued with has not been tested. New sources worth watching are equally welcome, especially ones with a lead time and a measured precision attached.
