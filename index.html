gledati (slav.) — to watch. What a good analyst does before speaking.

Free tools that turn public noise into structured signal — and hand it to an agent rather than to a dashboard nobody opens.

Each one is a real project, not a demo: you clone it, run it on your own machine, point it at your own subject, and keep the data. Same shape every time — watch a set of sources continuously, score and attribute what comes back, notice when several independent sources say the same thing, expose the result as something else can query.

01 the shape

Four moves, in this order. Every tool here is that pipeline pointed at a different subject.

  1. watch

    Public sources, on a cadence that fits how fast each one actually moves. Certificate logs and sitemaps, not just press releases.

  2. score

    Classify and weight each item, and record where it came from. An unattributed claim is not evidence.

  3. converge

    Find the patterns several independent sources corroborate. Ten mentions of one press release are one event, not ten.

  4. expose

    Serve it as structured data an agent can query — with a coverage block, so "nothing happened" reads differently from "we stopped looking".

03 previews

You should be able to see a tool before you install it. When one has something worth looking at, it gets a subdomain of its own. 

<tool>-<version>.gledach.de

signal-v1.gledach.de   ← a real deployment, exported to one static file
  • Real data, not a mock. The export asks the running viewer the same questions a browser asks and inlines the answers, so a preview cannot drift from the thing it was taken from.
  • Dated and read-only. It is a snapshot, not a live instance. Nothing you click reaches a database, and the numbers are true as of the export.
  • Versioned, never overwritten. v1 stays at v1. A rebuild that changes what you would conclude gets a new subdomain.
  • Generated analysis is model output — battlecards, briefs and convergences are written by a language model and are not verified fact. Read them as a starting point for a human, which is how the tool describes them too.

04 principles

Six commitments. They are the reason these tools are shaped the way they are.

  • local-first. The laptop is the runtime. Cloud is for sharing state.
  • convergence over alerts. One correlated insight beats ten raw mentions.
  • signal over polish. Output quality before dashboard aesthetics — but both.
  • say what you cannot see. Every tool ships an honest audit of its own blind spots.
  • read-only until asked. An agent does not spend your money because it found a button.
  • idempotent retry, not dual-write. Retry until it sticks; never split the source of truth.
