leash · slot 08 · examples

Copy-paste recipes.
Then see what the agent touched.

Copy-paste recipes for PowerShell. Attribution (leash run, --attach, --pid) needs an elevated window: right-click PowerShell → Run as administrator.

Agent flags change. These were checked in November 2026 against current CLI docs; if a flag errors, run the agent's own --help and keep the leash run wrapper the same.

leash is read-only. "YOLO" / skip-permissions modes are exactly when you want it watching — it records what happened, it does not block the agent.

Back to leash → Repository

AI coding agents

Claude Code (normal)

Start Claude in this folder and attribute everything it and its children touch.

leash run --path . -- claude

Claude Code (YOLO)

Skip permission prompts. Official docs say this is for an isolated environment; leash does not add a sandbox or a block-list.

leash run --path . -- claude --dangerously-skip-permissions

OpenAI Codex CLI (normal)

Start Codex in this folder and attribute its process tree.

leash run --path . -- codex

OpenAI Codex CLI (unattended / YOLO)

--full-auto was removed and now errors. Closest unattended workspace run: workspace-write sandbox, never ask for approval. Full bypass (no sandbox) is --yolo (same as --dangerously-bypass-approvals-and-sandbox). Official docs say yolo is for a hardened or isolated environment; leash does not provide one.

leash run --path . -- codex --sandbox workspace-write --ask-for-approval never
leash run --path . -- codex --yolo

Gemini CLI (normal)

leash run --path . -- gemini

Gemini CLI (YOLO)

Prefer --approval-mode=yolo. --yolo / -y still work but are deprecated. Do not pass both.

leash run --path . -- gemini --approval-mode=yolo

Aider

--yes-always is the current "don't ask" flag (AIDER_YES_ALWAYS also works). The older --yes is still accepted. Aider has no sandbox.

leash run --path . -- aider
leash run --path . -- aider --yes-always

Attach to something already open

Cursor, VS Code or Windsurf

Attaches to the editor process and every descendant: terminals, extension hosts, and an agent such as Claude running in the integrated terminal. Use leash ps if you are not sure what is visible.

leash start --path . --attach cursor
leash start --path . --attach vscode
leash start --path . --attach windsurf
# …work as usual…
leash stop

A named agent, or a pid

--attach claude matches claude.exe or a node.exe whose command line points at claude-code (npm shims show up as node.exe). That attaches only that subtree, not the whole editor.

leash ps
leash start --path . --attach claude
leash start --path . --pid 1234
leash stop

Untrusted commands

npm / pnpm install or a one-off tool

leash run --path . -- pnpm install
leash run --path . -- npm install
leash run --path . -- npx some-tool

Python script or pip

leash run --path . -- python script.py
leash run --path . -- pip install some-package

System-wide, no attribution

Same behaviour as the v0.1 preview. Every change on the PC during the session is listed, including other apps. Works without Administrator (file coverage is then a folder scan, not the USN journal).

leash start --path .
# …run whatever you like…
leash stop

Open the report

leash open              # report.html in the browser
leash open --md
leash open --json
leash open --folder     # session folder in Explorer
leash last              # reprint the short summary

Troubleshooting

The log is %LOCALAPPDATA%\leash\leash.log. Command-line reads that fail (often access denied when leash is not elevated) are written there rather than dropped silently. leash ps shows which editors and agents were detected, and why.

leash doctor
leash --verbose stop

PowerShell quoting and npm shims

Put -- in front of the agent so its flags are not eaten by leash. If PowerShell itself is swallowing arguments, stop-parsing with --%: claude, codex, gemini and similar tools installed with npm are often claude.cmd shims, not .exe files. leash run resolves PATHEXT and launches .cmd / .bat through cmd.exe /c, and .ps1 through PowerShell -File.

leash run --path . -- claude --dangerously-skip-permissions
leash run --path . --% -- claude --dangerously-skip-permissions
